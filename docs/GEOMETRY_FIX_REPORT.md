# 单元面积审计修复报告

> 2026-10-26 更新：本文数据属于 MUSCL 修复前的历史记录。Roe 能量特征向量错误及 MUSCL 当前验收见 [MUSCL_REPAIR_REPORT.md](MUSCL_REPAIR_REPORT.md)。旧并行计时未在新公式下重新认证。
## 问题与修复

网格单元四个顶点依次记为左下 `A`、右下 `B`、右上 `C`、左上 `D`。旧实现只计算

```text
cross(B - A, C - A)
```

这等于由两条边张成的平行四边形面积；对于喷管壁面高度沿轴向变化的梯形单元，它不是四边形面积。旧代码还使用绝对值，会掩盖顶点顺序反转。

CPU 和 CUDA/Kokkos 公共网格路径现在都调用 `src/mesh_geometry.hpp`，按边界顺序 `A-B-C-D` 使用有符号 shoelace 公式：

```text
V = 0.5 * sum(x_i*y_(i+1) - x_(i+1)*y_i)
```

只有有限且严格为正的面积才被接受，反向或退化单元会立即失败。单元中心也从“四顶点算术平均”改为四边形面积质心；对于一般梯形，算术平均同样不是严格质心。零长度面、非法面索引、非单位法向、单元—面连接错误和面向量不闭合也会被几何检查拒绝。

对于当前映射 `y=eta*h(x)`，第 `i,j` 个单元的离散精确面积为

```text
V_ij = dx * (h(x_i) + h(x_(i+1))) / ny
```

回归测试逐单元核对该表达式，而不是只检查总面积。旧公式在 64×16、128×32、256×64 网格上的最大局部相对误差分别约为 1.036%、0.519% 和 0.260%。

## 对求解流程的影响

- 显式更新中 `dt = CFL*V/sum(lambda*S)`，随后使用 `dt*R/V`，面积在该组合中代数消去；但残差范数 `R/V`、收敛时刻以及面积质心参与的初始化/重构仍会受影响。
- 隐式方向系统中的谱半径系数和右端都显式含有 `V`，因此必须重新验证，不能用共享面守恒测试代替面积测试。
- 面通量只计算一次、相邻单元取相反符号的守恒结构没有改变。

## 验收结果

自动测试覆盖矩形、平行四边形、非平行梯形、反向顶点、真实喷管逐单元面积、面向量闭合、直通道均匀流和 5×5 块 Thomas 求解；CPU-only、原生 CUDA 和 Kokkos OpenMP 三种构建的 CTest 均为 3/3 通过。AddressSanitizer 与 UndefinedBehaviorSanitizer 下的测试和完整 64×16 壅塞运行也通过，无越界、未定义行为或泄漏报告。
