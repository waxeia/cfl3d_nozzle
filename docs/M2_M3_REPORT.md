# M2–M3 数值验收报告

> 2026-10-26 更新：本文数据属于 MUSCL 修复前的历史记录。Roe 能量特征向量错误及 MUSCL 当前验收见 [MUSCL_REPAIR_REPORT.md](MUSCL_REPAIR_REPORT.md)。旧并行计时未在新公式下重新认证。
## M2 离散和判据

残差采用每个单元的向外面通量和 `R_i`，更新为 `U_i <- U_i - dt_i R_i/V_i`。局部步长是 `CFL*V_i/sum_f((|u_n|+c)S_f)`。`V_i` 采用四边形有符号 shoelace 面积，单元位置采用面积质心，详见 `GEOMETRY_FIX_REPORT.md`。一阶路径使用分片常数 Roe 类 FDS 通量；MUSCL 路径使用逐守恒量 minmod 斜率并以 0.5 重构幅度作正性保护。所有状态在写回前检查密度和压力，失败会缩小本轮步长并最终报告 `invalid_state`。

收敛要求是归一化 L2 残差 `<=1e-6`、入口/出口质量流率相对不平衡 `<=1e-3`，并要求最后 200 次迭代的出口质量流率和截面平均 `rho/u/p` 相对变化、`v` 相对入口声速的变化均 `<=1e-4`。达到 `max_iter` 只报告 `max_iter`。准一维程序 `reference/quasi1d.cpp` 对面积比方程显式使用亚声速/超声速分支，二维结果用中心线 Mach 与其插值作趋势对照。

## M3 方向隐式

`BlockThomas5` 先用 5×5 小矩阵 LU 解块，再执行块 Thomas 前消元/回代。`directionalCorrection` 沿 `xi=x` 的每条横向线和 `eta=y` 的每条轴向线各组装一个三对角近似系统，右端是当前显式残差，随后合并两个方向的增量并做正性回退。该系统是 CFL3D `af3f -> amafj/amafk -> vlutr/bsub` 的可核验 CPU 近似；边界线性化和完整通量 Jacobian 仍是简化项，映射文档已列出。
